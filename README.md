This game is a development of the skills I learned from the "target" tutorial in the assignment description and Google's HelloCardboard demo. Instead of a ball, I chose a cabbage. Instead of a target, I chose a box that holds the cabbages.

Additionally, I added a simple UI explaining the directions and displaying the score.
Assets used:

"Casual Vegetable Pack - Created with FastMesh Asset" — https://assetstore.unity.com/packages/3d/props/food/casual-vegetable-pack-created-with-fastmesh-asset-293783
"POLYGON - Starter Pack - Art by Synty" — https://assetstore.unity.com/packages/3d/environments/polygon-starter-pack-art-by-synty-156819

I also referenced the light and camera objects from the HelloCardboard demo.
